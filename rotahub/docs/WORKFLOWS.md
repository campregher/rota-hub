# Workflows

## Definition of Done
- Código revisado, lint e testes ok.
- Documentação atualizada.
- Sem vazamento de dados sensíveis em logs.

## Branching
- main: estável.
- feature/*: novas features.
- fix/*: correções.

## Testes
- `npm run test` no backend.
- Testes adicionais quando necessário.

## Release
- Gerar tag semver.
- Atualizar changelog.
